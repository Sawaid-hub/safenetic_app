Fall Detection

On-device machine learning analyzes accelerometer data from your phone and wearable devices to instantly detect falls. If you don't respond within a customizable countdown, your guardians are alerted automatically.

How Fall Detection Works

⚙️ How It Works

SafeNetic uses a TensorFlow Lite model running entirely on your device. It continuously reads accelerometer and gyroscope data, analyzing sudden deceleration patterns that match fall signatures. When a fall is detected, a 30-second countdown begins — if you don't cancel, an alert fires.

✨ Effects

  • Automatic emergency alert to all guardians
  • Live GPS location shared instantly
  • Works even when phone is locked
  • Zero battery drain — optimized ML pipeline

Distress Sound Recognition

Our audio classification model continuously listens for screams, breaking glass, and other distress sounds. When detected, SafeNetic triggers an automatic emergency response — no button press needed.

How Sound Recognition Works

⚙️ How It Works

An on-device audio classifier processes microphone input through a spectrogram pipeline. It's trained to recognize high-urgency sounds — screams, shattering glass, gunshots, and aggressive shouting — with high accuracy while ignoring false positives like music or TV.

✨ Effects

  • Hands-free emergency detection
  • Works in background — no app interaction needed
  • Privacy-first: audio is never recorded or uploaded
  • Instant alert with location to guardians

How One-Tap SOS Works

⚙️ How It Works

The SOS button is always visible on the main screen. One tap captures your current GPS coordinates, bundles them with a timestamp and your profile, then sends a high-priority push notification and SMS to every registered guardian simultaneously through Firebase Cloud Messaging.

✨ Effects

  • Sub-2-second alert delivery to all guardians
  • Direct Google Maps link for navigation
  • SMS fallback if guardian has no internet
  • Continuous location sharing during emergency

How Guardian Network Works

⚙️ How It Works

Guardians link via a unique pairing code or QR scan. Once connected, they automatically receive push notifications for all emergency events. The system uses Firebase Realtime Database to sync status, and each guardian gets a dedicated dashboard showing their dependents' safety status.

✨ Effects

  • Unlimited guardians per user
  • Real-time safety status dashboard
  • Two-way communication during emergencies
  • Notification history and event timeline
